# Hi, we're Little Vibe Coders! ⚡🤖

**Kids building real electronics with a little help from AI.**

We make videos where we come up with an idea, ask an AI to help write the code,
wire it up, and see what happens. Sometimes it works the first time. Usually it doesn't,
and figuring out why is the fun part.

## 🔧 What you'll find here

Each project from the channel gets its own repo, with:

- 📜 **The prompts** we gave the AI, so you can try them yourself
- 💾 **The code**, ready to flash onto your board
- 🛒 **A parts list**: what we used and where to get it
- 🪜 **Step-by-step instructions** for kids and grown-ups

## 👪 For grown-ups

Electronics projects here use low-voltage USB power. Please help younger builders with
soldering, sharp tools, and anything plugged into the wall. Never share personal
information when posting comments or issues.
